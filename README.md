# antics for Windows

Download **antics-Setup.exe** (version 1.0.1) and double-click it. Windows may say "Windows protected your PC": click **More info, Run anyway** (the app is not signed with a paid certificate). It installs antics with a desktop and Start-menu shortcut. antics opens the live site in its own window: https://tendha2020-ai.github.io/account-shop/animals/

Already have an older antics app? Install this one over it: your connection stays.
